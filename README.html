用量留在桌面。
更新在应用内完成。

Windows 10 / 11 · 64 位 · Chrome / Edge
桌面只接收官方页面上的可见用量数字。账号登录由浏览器与 OpenAI 官方网站管理。

这里不需要 GPT 密码、API Key 或 Cookie。
配对码只用于本次运行的本机同步。更新也不需要客户端 GitHub 登录或 PAT。

首次安装 / 从免安装版迁移

  1. 退出旧悬浮球，运行可信渠道的 GPT-Orb-Setup-2.1.3-x64.exe，完成一次安装迁移。
  2. 打开「GPT Usage Orb Safe」，点击「打开固定扩展文件夹」。这是当前用户数据目录中的固定 Browser-Extension，通常在 %APPDATA%\GPT Usage Orb Safe 下，以按钮打开的位置为准。
  3. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。开启「开发者模式」，加载这个固定目录。如果此前加载过旧解压目录，先移除旧项，再加载新目录一次。
  4. 访问 chatgpt.com/settings/usage?tab=overview。如需登录，只在确认地址正确的官方网站完成。
  5. 点击悬浮球「复制本次配对码」，从浏览器工具栏打开扩展，粘贴并点击「连接并开始读取」。保留官方用量页，检查面板读取状态。

不要双击 popup.html。普通文件页没有扩展消息 API，必须先加载扩展再从工具栏打开。2.1.3 保留了 sendMessage 不可用时的加载指引。

本扩展尚未上架商店。浏览器可能询问本地网络权限；它仅向本机 127.0.0.1:43861 同步数字。桌面退出、浏览器重启、扩展重载或更新后需要重新配对。

以后怎样更新

  1. 已配置发布源的安装版默认在启动约 10 秒后、之后每 6 小时检查更新。设置中可关闭自动检查，也可手动点击「检查更新」。
  2. 验证发布签名后自动下载，核对安装包完整性；准备好后点击「重启并更新」。安装前会再次校验，并备份显示设置与位置。
  3. 新版桌面启动时同步固定目录中的扩展文件。若扩展有更新，点击扩展内「重新加载扩展」，再重新复制配对码，无需每次移除重装。

普通退出不会自动安装待更新包。网络或校验失败会停止此次更新，当前版本仍可继续使用。更新包含桌面程序与 Electron 运行时，保留显示设置，不保留配对密钥。

显示「尚未配置更新源」？
只有发布仓库与签名公钥已配置的 Windows 安装版能在线更新。旧免安装版、开发运行或未配置源的试用安装包不会自动获得此功能。请等待发布者提供已启用的安装版，不要填入账号令牌。

设置里的「打开更新备份文件夹」可查看 recovery 文件夹。它只有偏好设置备份，不是完整程序快照或安装失败后的自动回滚。安装中断可能需要可信安装包修复；恢复设置前先退出程序，再将选定备份复制为用户数据目录中的 preferences.json。

已克隆源码时更新扩展

Windows 上已有 Node.js 22.12+ 与本仓库时，在仓库目录先执行 git pull --ff-only；成功后执行 npm run extension:update。无需 npm ci 或重装桌面程序。

命令只将扩展同步到 %APPDATA%\GPT Usage Orb Safe\Browser-Extension 并打印实际目录。若浏览器已加载该目录，在扩展管理页点击「重新加载」，确认版本 2.1.3 后重新配对。若仍加载 Downloads 下的旧目录，请先移除旧项，再加载固定目录一次；所选目录中必须直接包含 manifest.json。

此方式运行本地源码，不经过发布安装包的签名验证；请先检查来自可信仓库的变更。普通用户继续使用应用内的签名更新。

日常使用与数字含义

拖动悬浮球移动，点击展开 / 收起。托盘菜单和 Ctrl + Alt + G 可找回面板。设置中可调整置顶、透明度、额度提醒和开机启动；开机启动默认关闭。

显示内容含义
额度百分比只显示页面明确标注且能识别的窗口额度，不把不同窗口相加。
重置倒计时依据可识别的页面时间计算。归零后等待页面确认，不自行补满额度。
Token 数据页面确实显示且能识别时才有值，缺失项为「—」。不保证覆盖普通 ChatGPT 对话，也不是 API 账单。
页面读取时间表示扩展读取页面的时间，不表示官方后台刚更新统计。过期内容会标为上次记录。

网页关闭、跳转、休眠、后台限速或页面改版都可能停止同步。需要核对时，请直接查看官方用量页。工具不会额外调用模型、代发对话或改变官方额度。

页面无法识别时

在扩展展开「页面未识别？手动填写可见数值」，只填官方页面明确显示的数字，未知项留空。这里填写已用百分比：页面写「剩余 80%」，应填「已用 20%」。重置时间使用电脑本地时区。

手动提交后暂停自动读取，悬浮球标为「人工记录」，不会冒充后台实时数据。

账号、签名与安全边界

桌面没有 Codex 登录组件、OAuth 或账号接口调用；扩展不读取 Cookie、凭据文件、聊天内容或网页网络响应。本机服务验证来源、会话配对码与数字结构；渲染页面启用沙箱与上下文隔离。

更新通过 HTTPS 访问固定 GitHub Release 来源与 GitHub 资源域名，公钥随应用发布，安装包必须匹配签名描述。更新请求不含用量或 GPT 凭据，没有自建云同步或额外遥测。

Ed25519 更新签名不等于 Windows 发布者证书。当前程序没有 Windows Authenticode 签名，首次安装可能提示未知发布者；请从可信渠道取得安装包。本工具不是 OpenAI 官方应用，不能防御已控制电脑或浏览器的恶意软件。

断开、旧版凭据与卸载

设置中的「断开同步并使旧配对码失效」撤销本次配对，桌面退出也停止接收数字。若使用过 1.0.0 的登录功能，请单独确认旧版退出成功，必要时使用 OpenAI 官方会话管理。2.x 不读取、复用或删除旧版账号凭据。

卸载前关闭开机启动，退出程序，在浏览器移除扩展，再从 Windows「已安装的应用」卸载「GPT Usage Orb Safe」。用户数据目录默认保留设置、扩展和备份，确认不需要后可自行删除；这不会退出浏览器中的官方账号。
