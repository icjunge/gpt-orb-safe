首次连接本机 Codex

  1. 更新至可信渠道正式发布的 2.3.0 桌面安装版。已有安装版可检查签名更新；若新包尚未发布，可按下节运行源码。先退出旧悬浮球。
  2. 在 Windows PowerShell 执行 npm.cmd install -g @openai/codex，成功后执行 codex.cmd login，在官方流程中使用与网页版相同的 ChatGPT 账号登录。已安装并登录的用户无需重复。npm 安装需要 Node.js/npm；Windows 使用 .cmd 入口，无需更改 PowerShell 执行策略。
  3. 安装后重新打开终端与悬浮球，以取得最新环境。在概览「用量来源」选择「本机 Codex（实验性）」。填写整数 1–1440 分钟，默认 5，点击「保存间隔」，然后点击「开启自动读取」。
  4. 点击「立即刷新」，确认成功读取时间及额度。以后保持悬浮球运行即可，浏览器可以关闭。

界面提供「复制安装与登录命令」和「官方安装说明」，命令由你执行，工具不会自动安装或登录。首次官方登录可能打开浏览器，用量刷新不通过网页。API Key 登录不等于 ChatGPT 订阅登录，可能无法返回订阅额度。

首次默认未启用；主动开启后，间隔和启用偏好保留，桌面重启会继续查询。「停止读取」停止查询，不退出官方账号。切换来源后，切回本机 Codex 需再次开启。官方 CLI 是独立依赖，不随悬浮球打包或自动更新。

官方说明：Codex CLI · 认证与凭据 · App Server。

已有源码时运行新版

退出旧桌面程序。在可信仓库目录依次执行 git pull --ff-only、npm ci、npm start，每一步成功后再运行下一步。npm ci 需要网络下载固定依赖与 Electron，不要加 --ignore-scripts。

源码运行不更新原安装版，也不提供安装版自动更新；仅 npm run extension:update 不能启用 CLI 来源。源码提交和草稿 Release 不等于正式安装包已发布。

读数表示什么

显示内容含义
额度窗口官方返回的已用 / 剩余比例，各窗口独立，不相加。
重置倒计时依据官方返回时间计算，归零不自行补满额度。
剩余重置次数仅在响应提供时显示，未知为「—」。不会执行重置。
独立额度仅展示实际返回记录；没有 Spark 记录时不编造独立周额度。
最近一日 Token协议支持时返回的服务端最新日桶，显示对应日期；不是本机今日 Token。
服务端累计 Token官方返回范围内的累计；不扫描本机日志，不承诺覆盖全部 ChatGPT 对话或 API 账单。
成功读取时间表示查询成功，不代表官方服务器统计刚刚更新。

CLI 缺失、登录过期、离线或接口变化时显示提示，保留上次成功记录和时间；未知项不推算。电脑休眠和服务端统计延迟会影响更新。App Server 属实验性接口，不能保证所有 CLI 版本与账号结构都兼容。

浏览器扩展作为备用

  1. 概览「用量来源」选择「浏览器扩展（备用）」。打开固定扩展文件夹，通常是 %APPDATA%\GPT Usage Orb Safe\Browser-Extension。
  2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions，开启开发者模式并加载该目录。选中的目录必须直接含 manifest.json，不要双击 popup.html。
  3. 访问 官方用量页并完成官方登录。复制悬浮球当前配对码，在浏览器工具栏的扩展中粘贴并连接。

当前页面模式需保留用量页。扩展的备用「后台定时刷新」需主动授予 https://chatgpt.com/* 权限，每轮临时打开非活动用量页；只清理本轮创建且未被用户接管的页面。浏览器授权覆盖整个来源，代码只接受两个精确用量路径。

浏览器备用模式需要浏览器运行，本机 Codex 模式不需要。桌面退出、浏览器重启或扩展重载会使配对失效，扩展重启还需重新开启定时。迁移到本机 Codex 前，请在扩展点击「关闭并撤销授权」，避免旧任务继续尝试打开页面。

只维护扩展时，在可信仓库执行 git pull --ff-only，成功后执行 npm run extension:update，再在浏览器重新加载并配对。该命令不更新桌面。浏览器仍加载 Downloads 旧目录时需先迁移到固定目录一次。

日常使用与应用更新

拖动悬浮球移动，点击展开 / 收起。托盘及 Ctrl + Alt + G 可找回面板。设置可调整置顶、透明度、提醒和开机启动，开机启动默认关闭。

已配置更新源的安装版启动约 10 秒后、此后每 6 小时检查更新，也可手动检查。验证 Ed25519 发布签名后下载，再校验完整性；由你点击「重启并更新」。普通退出不安装待更新包，失败保留当前版本。更新包含桌面、Electron 和备用扩展，不包含官方 CLI。

显示设置和位置保留。固定目录的扩展若更新需在浏览器手动重新加载，重新配对；仅使用本机 Codex 无需加载扩展。开发运行、旧便携版和未配置发布源的安装版没有安装版自动更新能力。

安装前在 recovery 备份偏好设置，不是完整程序快照或 NSIS 原子回滚。安装中断可能需可信安装包修复；手动恢复设置前先退出程序。

账号和安全边界

悬浮球通过 stdio 发送固定查询，不读取或复制 auth.json、Cookie、密码或令牌，不记录原始 RPC，不扫描本机会话日志。官方 CLI 自己管理登录及续期，可能读写自己的凭据；文件或系统凭据库存储取决于原配置，不能承诺天然加密。

浏览器备用模式只向 127.0.0.1:43861 发送数值，校验来源、配对与字段。切换来源不会因 CLI 失败而自动打开网页，也不把两种记录混成账号总量。

更新访问固定 GitHub Release 来源，不含用量和账号凭据，不需要客户端 GitHub 登录或 PAT。没有自建云用量同步或额外遥测。Ed25519 更新签名不等于 Windows Authenticode 发布者证书，当前没有 Windows 发布者签名。

本工具不能防御已控制本机、CLI 或浏览器的恶意软件。停止读取或卸载不等于退出官方登录；需要时自行使用 codex.cmd logout。1.0.0 的旧凭据仍需单独通过旧版或官方会话管理撤销。

验证与卸载

自动测试使用合成协议和数据，覆盖查询、异常、来源切换、数据校验及既有更新边界。真实 Windows 安装 / 升级、官方 CLI 登录及账号额度仍需实机验收。已有 Electron / MV3 检查也不等于完整 Chrome / Edge 权限流程通过。

卸载前停止开机启动并退出悬浮球，不再使用扩展时在浏览器移除，再从 Windows 已安装应用卸载。用户目录默认保留设置和备份。卸载悬浮球不卸载 CLI，也不退出官方账号。
