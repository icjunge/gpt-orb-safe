GPT 悬浮球 · 浏览器扩展 2.1.2

推荐更新方式：先将旧免安装版迁移到 2.1.2 安装版一次。
1. 退出旧桌面程序，运行可信渠道提供的 GPT-Orb-Setup-2.1.2-x64.exe。
2. 在新版悬浮球中点击「打开固定扩展文件夹」。它指向当前用户数据目录下固定的 Browser-Extension。
3. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
4. 若此前加载过旧解压目录的扩展，先移除旧项，再开启开发者模式，加载上一步固定目录。这只需做一次。
5. 打开 https://chatgpt.com/codex/settings/usage，点击工具栏中的扩展图标，用桌面提供的本次配对码重新配对。

之后：配置了发布源的安装版会检查并下载桌面更新，点击「重启并更新」安装。桌面启动时同步扩展文件；在扩展弹窗点击「重新加载扩展」后重新配对，无需每次移除或重装扩展。

这份小型 ZIP 只包含扩展，不会给旧桌面程序添加应用内更新功能。如果暂时继续使用 2.0.x 桌面版，可将本 ZIP 的 Browser-Extension 保存在固定目录并在浏览器加载；之后迁移到安装版时，仍需改为新版桌面按钮打开的固定目录。

不要双击 popup.html；它必须作为扩展从浏览器工具栏打开。2.1.2 保留 sendMessage 不可用时的加载提示，并提供本地「重新加载扩展」按钮；没有新增浏览器权限或远程脚本。

配对码只用于本机数值同步，不是 GPT 登录码。不要填写密码、API Key、Cookie 或官方验证码。桌面退出、浏览器重启、扩展重载或更新后必须重新配对。未知数据保持未知，以官方页面显示为准。

已克隆源码的 Windows 使用者也可在仓库目录运行：
git pull --ff-only
拉取成功后：npm run extension:update
此命令无需 npm ci，只更新 %APPDATA%\GPT Usage Orb Safe\Browser-Extension，打印实际路径，不自动重载浏览器。已加载固定目录时，点击「重新加载」后确认扩展为 2.1.2，再重新配对。若仍加载 Downloads 下旧目录，请按上面的步骤迁移一次；更新固定目录不会修改旧目录。
这是本地源码维护方式，不经过发布安装包的签名验证；请只运行可信仓库代码。普通用户继续使用应用内签名更新。
