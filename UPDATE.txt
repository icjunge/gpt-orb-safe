GPT 悬浮球 · 浏览器扩展 2.2.0

已有源码仓库时，无需重新安装桌面程序。进入仓库的 PowerShell：
git pull --ff-only
拉取成功后：npm run extension:update

命令无需 npm ci，只更新 %APPDATA%\GPT Usage Orb Safe\Browser-Extension 并打印实际路径，不自动重载浏览器。Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。点击扩展「重新加载」，确认版本 2.2.0，再复制悬浮球当前配对码重新连接。

若浏览器仍加载 Downloads 中的旧目录，先移除旧项，再开启开发者模式，加载命令输出的固定目录；只需迁移一次。选中的目录内必须直接包含 manifest.json，不要选择外层解压目录。不要双击 popup.html，必须从浏览器工具栏打开扩展。

关闭用量页后定时刷新：
1. 打开 https://chatgpt.com/settings/usage?tab=overview，在官方网站完成登录并配对。
2. 在扩展「后台定时刷新」设置整数 1–1440 分钟的间隔（默认 5），点击「开启后台刷新」，授予 chatgpt.com 可选网站权限；已有授权时可能不再弹窗。拒绝不影响当前页读取。之后更改周期，点击「保存刷新间隔」。
3. 可关闭原来的用量页。每轮扩展打开不抢焦点的临时官方用量标签页，读取可识别 DOM 数字，再关闭本轮创建且未被用户接管的页；不会刷新或关闭已有页面。可点击「立即刷新」，或「关闭并撤销授权」停止任务并撤销后台网站权限。

浏览器和悬浮球须运行，官方网站须保持登录；电脑休眠、关闭浏览器、退出登录、网站验证或限速都可能阻止读取。浏览器定时不保证精确准点。配对码和启用状态只存当前会话，浏览器重启或扩展重载后须重新配对并开启；仅间隔数字长期保留。切回当前页面或人工记录模式只停止任务，可能保留网站授权；要撤销请使用「关闭并撤销授权」或浏览器扩展管理。

登录凭据由浏览器与官方网站保管，不复制到本工具；没有 Cookie API 或私有账号接口。新增基础 alarms 权限及可选 https://chatgpt.com/* 来源权限，后者在浏览器层面覆盖整个来源，但采集代码只接受两个精确官方用量路径。

失败或未识别不会覆盖上次成功读数或更新成功时间。桌面超过 3 分钟未接收到数据会显示历史记录；刷新间隔大于 3 分钟时可能正常出现此提示，旧桌面可能仍显示「页面读取已超时」；请结合间隔和扩展状态判断。读取时间不是官方服务器统计更新时间，不猜测 Token 总数，也不自行重置额度。

2.1.1 等旧桌面不认识新清单，启动时可能显示「扩展目录无法安全更新」，但会保留新版扩展文件，数字同步兼容。待正式发布的桌面版本升级到 2.2.0 后解除警告。新版本地辅助命令可以校验并迁移旧扩展，保留完整备份。

这是本地源码维护方式，不经过发布安装包签名验证，只运行可信仓库代码。普通安装版仍使用应用内签名更新；源码已更新不代表新 NSIS 安装包已发布。这份 ZIP 只包含扩展，不改变桌面版本或给旧便携程序添加更新功能。

配对码只用于本机数值同步，不是 GPT 登录码。不要填写密码、API Key、Cookie 或官方验证码。桌面退出也使旧配对码失效。未知数据保持未知，以官方页面为准。
