GPT 悬浮球 · 浏览器扩展 2.7.0（备用来源）

这份 ZIP 只包含浏览器扩展。2.3.0 起提供的官方 Codex CLI 定时读取在桌面主进程中，必须更新桌面；仅更新或重载扩展不能启用它。

普通用户使用桌面一键连接：
1. 从 https://github.com/icjunge/gpt-orb-safe/releases/latest 下载对应电脑的正式安装包：Windows x64 用 EXE，Mac M 系列用 arm64.dmg，Intel Mac 用 x64.dmg。Mac 支持 macOS 13+，打开 DMG 后将应用拖入「应用程序」再启动。Windows 现有安装版可检查更新并「重启并更新」。
2. 点击「连接 Codex」。首次下载约 80–90 MB 的固定官方组件，校验后缓存，无需 Node.js、Git、npm 或命令行。
3. 在自动打开的 OpenAI 官方页面登录自己的账号。登录成功后自动显示额度，默认每 5 分钟刷新；设置可改为 1–1440 分钟，之后浏览器可关闭。

自动配置的登录由官方组件保存在 Windows 凭据库 / macOS 钥匙串，使用独立目录，不复用或覆盖本机已有 Codex。系统凭据库不可用时会失败，不退回明文文件。「暂停」只停刷新；「退出此账号」退出此工具的独立登录。登录失效可重新连接，连接过程中可以取消。卸载和删除用户目录不等于退出账号。

升级保留已有 CLI 连接方式和偏好。高级用户可在「已有 Codex / 手动设置」中选「使用本机已安装的 Codex」，自行安装并登录 CLI，再开启读取；只有手动 npm 安装才需要 Node.js/npm。应用不会代此模式退出已有 CLI。切换到「自动配置（推荐）」后可使用一键连接。

官方登录不是专门的用量只读 OAuth。悬浮球限制自身业务操作，只查询用量，不发起模型任务或重置额度；不读取或复制 auth.json，不记录原始 RPC，也不扫描会话日志。Token 是协议支持时的服务端统计，不是本机今日总数；未知时隐藏，普通查询失败保留上次记录，退出或账号变化清除旧读数。

分享给朋友只需正式 Release 链接，让对方选择对应系统与芯片的安装包。不要打包用户数据目录、登录状态、配对码或发布私钥。

Mac 首版仅作 ad-hoc 签名，没有 Apple Developer ID 签名或公证。确认来源后，如提示无法验证开发者，先尝试打开，再按 Apple 官方说明 https://support.apple.com/102445 在「系统设置 → 隐私与安全性」选择「仍要打开」。若提示已损坏或含恶意软件，请停止使用并核对下载，不关闭系统安全检查。

Mac 在应用内检查更新，验证对应架构的 Ed25519 发布描述；点击「下载 Mac 新版」后在浏览器下载 DMG，退出应用并替换「应用程序」中的旧版，保留偏好与独立登录。应用不校验浏览器下载的 DMG，也不自动安装。Windows 保留应用内校验后「重启并更新」。Ed25519 不等于 Windows 发布者证书或 Apple 公证。

Mac 左键点击菜单栏图标展开面板，右键打开菜单；⌘ + ⌥ + G 可找回面板。开机启动可能需要系统「登录项」允许，未公证版本不保证系统接受。透明圆球与原生毛玻璃面板无需屏幕录制或辅助功能权限。

若仍需要浏览器备用模式：
1. 桌面设置「数据来源」选择「浏览器扩展」。
2. 已克隆仓库时先 git pull --ff-only，成功后 npm run extension:update（无需 npm ci）。命令只更新固定扩展目录，打印实际路径，不自动重载浏览器、不改变桌面版本。
3. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。已有固定目录扩展点击「重新加载」，确认 2.7.0 后重新配对。若加载的是 Downloads 旧目录，移除旧项，开启开发者模式，加载固定目录一次。直接使用本 ZIP 时选择解压后的 Browser-Extension 子目录，其中必须直接包含 manifest.json，不选外层目录。
4. 打开 https://chatgpt.com/settings/usage?tab=overview，只在官方网站登录。复制悬浮球当前配对码，从浏览器工具栏打开扩展并粘贴连接。不要双击 popup.html。

浏览器模式的「后台定时刷新」仍会创建非活动临时页面，要求浏览器和悬浮球运行、官方登录有效；授权 chatgpt.com 来源覆盖整个来源，采集代码只接受两个精确用量路径。间隔 1–1440 分钟，默认 5。配对和启用只存当前会话，浏览器重启/扩展重载后重新配对并开启。桌面退出也使配对失效。

从浏览器方案切换到本机 Codex 时，先在扩展点击「关闭并撤销授权」，防止旧会话定时器继续尝试打开页面。也可从浏览器移除不再使用的扩展。浏览器模式的失败不覆盖成功时间，旧桌面可能仍有 3 分钟过期提示和新清单校验警告；桌面升级后使用新版逻辑。

仅运行可信仓库代码。本源码路径不经过安装包签名验证；普通安装版继续使用原有签名更新。官方 App Server 为实验性接口，真实 Windows / Mac 及账号读取仍需验收。
