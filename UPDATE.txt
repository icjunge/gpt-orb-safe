GPT 悬浮球 · 浏览器扩展 2.5.0（备用来源）

这份 ZIP 只包含浏览器扩展。2.3.0 起提供的官方 Codex CLI 定时读取在桌面主进程中，必须更新桌面；仅更新或重载扩展不能启用它。

使用本机 Codex（推荐先阅读桌面使用说明）：
1. 更新至已正式发布的 2.5.0 桌面安装版，或退出旧程序后运行可信源码（npm ci 后 npm start）。源码提交不等于正式安装包已发布。
2. 在 PowerShell 安装官方 CLI：npm.cmd install -g @openai/codex
3. 安装成功后执行 codex.cmd login，按官方流程登录与网页版相同的 ChatGPT 账号。安装后重新打开终端与悬浮球。Windows 使用 .cmd 入口，无需更改 PowerShell 执行策略。不要向悬浮球填写官方验证码或令牌。
4. 设置「数据来源」选择「本机 Codex」，设置 1–1440 分钟（默认 5），「保存」后「开启读取」，可「立即刷新」验证。以后无需浏览器运行，也不会临时打开网页。

本机读取需用户主动开启，启用及间隔偏好跨桌面重启保留；「暂停」不退出官方 CLI。切换来源后切回本机需再次开启。官方 CLI 管理本机登录与续期；悬浮球不读取或复制 auth.json，不记录原始 RPC，不扫描会话日志，不发起模型任务或自动重置额度。凭据的文件/系统库保存方式取决于官方既有配置。Token 是协议支持时的服务端累计与最新日桶，不是本机今日总数。Token 未提供时隐藏，其他未知项为「—」，普通失败保留上次有效记录；检测到退出登录或账号变化时清除旧账号记录。

若仍需要浏览器备用模式：
1. 桌面设置「数据来源」选择「浏览器扩展」。
2. 已克隆仓库时先 git pull --ff-only，成功后 npm run extension:update（无需 npm ci）。命令只更新固定扩展目录，打印实际路径，不自动重载浏览器、不改变桌面版本。
3. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。已有固定目录扩展点击「重新加载」，确认 2.5.0 后重新配对。若加载的是 Downloads 旧目录，移除旧项，开启开发者模式，加载固定目录一次。直接使用本 ZIP 时选择解压后的 Browser-Extension 子目录，其中必须直接包含 manifest.json，不选外层目录。
4. 打开 https://chatgpt.com/settings/usage?tab=overview，只在官方网站登录。复制悬浮球当前配对码，从浏览器工具栏打开扩展并粘贴连接。不要双击 popup.html。

浏览器模式的「后台定时刷新」仍会创建非活动临时页面，要求浏览器和悬浮球运行、官方登录有效；授权 chatgpt.com 来源覆盖整个来源，采集代码只接受两个精确用量路径。间隔 1–1440 分钟，默认 5。配对和启用只存当前会话，浏览器重启/扩展重载后重新配对并开启。桌面退出也使配对失效。

从浏览器方案切换到本机 Codex 时，先在扩展点击「关闭并撤销授权」，防止旧会话定时器继续尝试打开页面。也可从浏览器移除不再使用的扩展。浏览器模式的失败不覆盖成功时间，旧桌面可能仍有 3 分钟过期提示和新清单校验警告；桌面升级后使用新版逻辑。

仅运行可信仓库代码。本源码路径不经过安装包签名验证；普通安装版继续使用原有签名更新。官方 App Server 为实验性接口，真实 Windows 及账号读取仍需验收。

官方认证：https://learn.chatgpt.com/docs/auth
配对码只授权本机数字同步，不是 GPT 登录码。不要填写密码、API Key、Cookie 或设备授权码。
