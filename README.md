# GPT 悬浮球 · 2.1.3

Windows 10 / 11（64 位）桌面悬浮球，通过 Chrome / Edge 扩展同步官方用量页上可见的数字。**桌面程序不登录 GPT 账号，不获取账号密码、Cookie 或访问令牌。**

2.1 系列支持安装版和应用内更新：发布者配置好仓库与签名公钥后，程序自动检查并下载新版本，你点击「重启并更新」即可。浏览器扩展保存在固定目录，后续更新不必移除再安装。

## 第一次使用 / 从 2.0.x 迁移

1. 退出旧版悬浮球，运行可信发布渠道提供的 `GPT-Orb-Setup-2.1.3-x64.exe`。这是从免安装包迁移到安装版所需的一次安装；新旧版本不要同时运行。
2. 打开「GPT Usage Orb Safe」。原来同一 Windows 用户下的显示设置与悬浮球位置会继续读取。开机启动默认关闭；已开启的设置会改用新安装路径。
3. 在面板点击「打开固定扩展文件夹」。这是当前用户数据目录下的固定 `Browser-Extension` 文件夹，通常为 `%APPDATA%\GPT Usage Orb Safe\Browser-Extension`，以按钮打开的位置为准。
4. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。开启「开发者模式」，点击「加载已解压的扩展程序」，选择上一步的文件夹。**如果此前加载的是旧解压目录中的扩展，需要先移除旧项，再加载这个固定目录一次。**
5. 用浏览器打开 <https://chatgpt.com/settings/usage?tab=overview>；如需登录，只在确认地址无误的官方网站完成。
6. 点击悬浮球的「复制本次配对码」，从浏览器工具栏打开本扩展，粘贴配对码，点击「连接并开始读取」。保留官方用量页，查看面板中的读取状态。

不要双击 `popup.html`。普通文件页面没有扩展消息 API，程序会给出加载指引；应先加载扩展，再从浏览器工具栏打开。这保留了 2.0.1 对 `Cannot read properties of undefined (reading 'sendMessage')` 的修复。

本扩展尚未上架浏览器商店。浏览器如询问本地网络访问权限，是向本机 `127.0.0.1:43861` 同步数字所需。配对码**不是 GPT 登录码**；不要粘贴密码、API Key、Cookie、访问令牌或官方验证码。桌面程序退出、浏览器重启、扩展重新加载或更新后，都需要重新配对。

## 以后怎样更新

- 安装版默认在启动约 10 秒后检查更新，运行期间每 6 小时再检查；可以在设置中关闭自动检查，或手动点击「检查更新」。检查发现新版本后会自动下载。
- 下载前验证发布描述的 Ed25519 签名，并核对版本、安装包名称、长度和哈希。下载完成后显示「重启并更新」；点击后再次校验安装包，备份设置，再启动安装程序。
- 更新包含桌面程序及 Electron 运行时。设置与悬浮球位置保留；配对码不持久保存，重启后重新配对。
- 桌面程序启动时将随包扩展同步到固定目录。若扩展有更新，从扩展弹窗点击「重新加载扩展」，然后重新配对；无需每次移除扩展或重新选择目录。浏览器管理页的「重新加载」也可使用。
- 网络、签名或完整性检查失败时，会显示错误并停止此次更新，当前版本可继续使用。已下载的新版本不会因普通退出而自动安装。

**只有已配置发布源的 Windows 安装版才能在线更新。** 源码中的 `update-config.json` 必须含实际仓库和公钥；两项为 `null` 时是停用状态。开发运行、旧免安装包或未配置发布源的试用安装包，不会自动获得这个能力。界面显示「尚未配置」时，请等待发布者提供已启用的安装版；不要向配置中填入账号令牌。

配置备份位于当前用户数据目录的 `recovery` 文件夹，可从设置打开。备份仅包含显示设置和位置，**不是完整程序快照，也不是 NSIS 安装失败后的自动回滚**。安装中断时可重新运行同版本或较新版本的可信安装包修复；如需恢复设置，请先退出程序，将所需备份复制为用户数据目录中的 `preferences.json`。卸载旧版本不等于撤销浏览器中的官方登录。

## 从已克隆的源码更新扩展（Windows）

已有 Node.js 22.12+ 和本仓库的使用者，可以先取得代码，再只更新本机扩展，无需重装桌面程序，也无需 `npm ci`。在仓库目录的 PowerShell 中运行：

```powershell
git pull --ff-only
if ($LASTEXITCODE -eq 0) { npm run extension:update }
```

命令只使用 Node.js 内置模块，将仓库的扩展同步到 `%APPDATA%\GPT Usage Orb Safe\Browser-Extension`，并打印实际目录。它复用桌面程序的完整包校验、替换恢复和防降级逻辑；不会读取浏览器配置、访问网络、启动程序或自动重载扩展。2.1.1 桌面程序随后启动时会保留更高版本的扩展。

- 浏览器已经加载这个固定目录：到扩展管理页点击「重新加载」，确认版本为 2.1.3，再从官方用量页打开扩展并重新配对。
- 浏览器仍加载 `Downloads` 或其他解压目录：同步固定目录不会改变浏览器正在使用的路径。先移除旧扩展项，再「加载已解压的扩展程序」选择命令打印的固定目录；只需迁移一次。所选目录中必须直接包含 `manifest.json`。

这是运行本地源码的维护方式，不经过已发布安装包的更新签名验证；应使用可信仓库并先检查拉取的变更。普通用户继续使用应用内的签名更新。仅推送源码不会自动发布安装包。

只更新扩展时，旧桌面程序的「打开官方用量页面」按钮仍可能使用旧地址。此时使用扩展中的新链接或直接打开 <https://chatgpt.com/settings/usage?tab=overview>，待桌面程序更新后入口会一并修正。新页面可识别字段取决于实际可见布局；连接成功不代表所有指标都能解析，未知字段仍显示「—」。

## 日常使用与数据含义

拖动悬浮球调整位置，点击展开 / 收起面板。托盘菜单和 `Ctrl + Alt + G` 可找回面板。置顶、透明度、额度提醒和开机启动可在设置中调整。「断开同步并使旧配对码失效」会撤销本次配对。

| 项目 | 含义 |
|---|---|
| 额度百分比 | 只识别页面清楚标注的已用 / 剩余额度，不把不同窗口相加 |
| 重置倒计时 | 依据可识别的页面重置时间计算；归零不会自行把额度补满 |
| Token 数据 | 页面确实显示且解析器能识别时才有值，缺失项显示「—」 |
| 页面读取时间 | 表示扩展读取页面的时间，不代表官方后台刚更新统计 |
| 统计范围 | 以当前官方用量页显示范围为准；不保证覆盖所有普通 ChatGPT 对话，也不是 API 账单 |

网页关闭、跳转、休眠、浏览器后台限速或页面改版，都可能停止同步。需要核对数据时，请在浏览器刷新并查看官方页面。工具不会额外调用模型、代发对话或修改官方额度，也不会猜测页面没有提供的 Token 总数。

若页面无法识别，可以在扩展中展开「页面未识别？手动填写可见数值」，只填写页面明确显示的数字，未知项留空。填写的是**已用百分比**：页面写「剩余 80%」时应填「已用 20%」。手动提交后暂停自动读取，悬浮球标记为「人工记录」；重置时间使用电脑本地时区。

## 账号与更新安全边界

- 登录由浏览器和 OpenAI 官方网站管理。本工具不读取浏览器 Cookie、账号凭据文件、聊天内容或网页网络响应，没有 Codex 登录组件、OAuth 或账号接口调用。
- 扩展仅申请 `activeTab`、`scripting`、`storage` 和本机同步权限；点击扩展后，仅在指定官方用量页采集可识别的可见指标，不申请所有网站的访问权限。
- 数值同步仅到 `127.0.0.1`，接收端验证扩展来源、会话配对码与数据结构；配对码不写入普通配置文件。
- 更新功能会通过 HTTPS 访问安装包中固定的 GitHub Release 来源及 GitHub 资源域名，不向客户端要求 GitHub 登录或 PAT。更新请求不包含用量数据或 GPT 凭据。
- 更新签名公钥随应用发布，私钥只由发布者保管。**Ed25519 更新签名不等于 Windows Authenticode 发布者证书**；当前安装包没有 Windows 发布者签名，系统可能提示未知发布者。

没有自建云同步或额外遥测。首次安装包仍需从可信渠道取得；本设计无法防御已经控制电脑或浏览器的恶意软件。详细说明见 [SECURITY.md](SECURITY.md)。

## 旧版凭据、卸载与验证限制

如果使用过 1.0.0 的登录功能，请单独确认旧版退出登录成功，必要时使用 OpenAI 官方账号安全页面提供的会话管理选项。2.x 不读取、复用或删除旧版已保存的账号凭据；仅删除旧程序不代表这些会话已经撤销。

卸载时先关闭开机启动并退出程序，在浏览器移除本扩展，再到 Windows「已安装的应用」卸载「GPT Usage Orb Safe」。卸载默认保留用户数据目录中的设置、扩展文件与备份；确认不再需要后可自行删除。卸载本工具不影响浏览器中的官方登录。

验证覆盖 Node.js 边界与更新流程测试、合成页面 DOM、离屏桌面界面，以及 Electron Chromium 中实际 MV3 弹窗和扩展后台到本机服务的传输。更新流程测试包括签名不匹配、来源限制、篡改安装包和设置备份等情况。**这不等于实体 Windows 安装 / 升级验收，也不等于完整 Chrome / Edge 工具栏、临时页面授权与本地网络权限流程验收。** 当前未使用真实账号验证页面布局；实际浏览器版本、企业策略与官方页面变动仍可能影响运行。

## 源码、打包与发布

代码仓库：<https://github.com/icjunge/gpt-orb-safe>。GitHub Actions 会运行 Linux / Windows 测试，并在 Windows 验证安装包构建；这不代表已发布可下载的正式版本。

首次启用签名发布，维护者可按 [RELEASE.md](RELEASE.md) 的「一次性本地初始化」运行设置脚本。私钥在维护者自己的电脑生成，写入 GitHub 的受保护发布环境；不需要把私钥发给任何聊天。此步骤只做一次，普通悬浮球用户不需要安装开发工具。

使用 Node.js 22.12+，执行 `npm ci`、`npm test`；`npm start` 以固定版本 Electron 启动。在 Windows 构建环境运行 `npm run build:win`，生成 Windows x64 NSIS 安装包。生成源码和小型扩展压缩包：

```sh
python scripts/package_windows.py --source-only --extension-zip --output dist
```

运行安装后的程序不需要 Node.js 或 Python。维护者的仓库、公钥、发布私钥、版本标签与 GitHub Actions 配置步骤见 [RELEASE.md](RELEASE.md)。只修改版本号或创建代码仓库不会自动启用客户端更新；发布源与签名配置必须在首次发行前完成。

应用代码采用 MIT 许可；Electron、Chromium 及 npm 运行依赖保留各自许可。本工具由独立开发者制作，不是 OpenAI 官方应用。
