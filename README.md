# GPT 悬浮球 · 2.7.0

适用于 Windows 10 / 11（x64）与 macOS 13+（Apple Silicon / Intel）的常驻桌面 Codex 额度监控工具。**安装 → 点击「连接 Codex」→ 官方网页登录，完成后自动显示额度。** 普通用户无需安装 Node.js、Git 或执行命令。关闭浏览器后仍按设定间隔刷新；浏览器扩展保留为备用来源。

悬浮球只查询用量，不发起模型任务，不代发对话，不自动消耗重置次数。登录由官方 Codex 管理；悬浮球不读取或复制 `auth.json`、Cookie、密码或访问令牌。

**本版新增 Mac 版。** 保留百分比圆球、悬停放大与定时刷新，Mac 面板使用系统毛玻璃材质。首次点击连接后才准备官方组件并打开登录页；安装和首次启动不会自行登录或读取账号。

## 第一次使用

从 [正式发布页](https://github.com/icjunge/gpt-orb-safe/releases/latest) 选择与你的电脑匹配的安装包；普通用户不需要源码 ZIP 或浏览器扩展 ZIP。

| 电脑 | 安装包 | 安装方式 |
|---|---|---|
| Windows 10 / 11，x64 | `GPT-Orb-Setup-X.Y.Z-x64.exe` | 运行安装器 |
| Mac，Apple Silicon（M 系列） | `GPT-Orb-Setup-X.Y.Z-arm64.dmg` | 打开 DMG，将应用拖到「应用程序」 |
| Mac，Intel | `GPT-Orb-Setup-X.Y.Z-x64.dmg` | 打开 DMG，将应用拖到「应用程序」 |

Mac 可在「 → 关于本机」查看芯片；安装后从「应用程序」打开，不在 DMG 内长期运行。首次 Mac 版未使用 Apple Developer ID 签名或公证。如果系统提示无法验证开发者，在确认下载来自本仓库后，按 [Apple 官方说明](https://support.apple.com/102445)，先尝试打开，再进入「系统设置 → 隐私与安全性 → 仍要打开」。这只针对未识别开发者的提示；若提示应用已损坏或含恶意软件，请停止使用并核对下载，不关闭系统安全检查。

1. 打开悬浮球，点击 **「连接 Codex」**。首次约需下载 **80–90 MB** 官方组件，界面显示进度，可随时取消；下载速度取决于网络。组件校验通过后缓存复用，同一组件版本不会每次启动或更新界面时重新下载。
2. 在自动打开的 **OpenAI 官方页面** 登录自己的 ChatGPT 账号，按官方要求完成验证。悬浮球不索取密码、验证码或令牌。
3. 登录成功后自动读取用量，默认 **每 5 分钟** 刷新。此后保持悬浮球运行即可，浏览器可以关闭。在设置中可改为 **1–1440 分钟**，也可立即刷新。

连接失败时按提示「重新连接」；等待登录时可「取消」。登录过期需要重新连接。使用 API Key 不等于 ChatGPT 订阅登录，不能据此保证获得订阅额度。

自动配置使用独立的本机登录，由官方组件保存到 **Windows 凭据库 / macOS 钥匙串**；凭据库不可用时连接失败，不退回明文文件。它不会复用或覆盖你已有 Codex 的登录。官方组件固定为 **0.134.0**，从 OpenAI 官方 GitHub Release 下载；应用验证压缩包及可执行文件的固定长度和 SHA-256 后才运行。

### 已经在使用旧版或本机 Codex？

升级保留已有的连接方式与刷新设置，不强制重新登录。想改用一键连接，在「设置 → 已有 Codex / 手动设置 → 连接方式」选择「自动配置（推荐）」，再点击「连接 Codex」。切换方式会停止刷新、清空当前读数，但不退出原登录。

## 已有源码时直接运行新版

先退出已安装的旧悬浮球，避免旧进程占用同一运行实例。在已经克隆的仓库目录运行（将示例路径替换为实际位置）：

```powershell
cd C:\path\to\gpt-orb-safe
git pull --ff-only
if ($LASTEXITCODE -eq 0) {
    npm ci
    if ($LASTEXITCODE -eq 0) { npm start }
}
```

`npm ci` 按 lockfile 安装依赖及 Electron 运行时，需要可用网络。这里不要加 `--ignore-scripts`：那会跳过 Electron 的运行时安装。源码运行不改变已安装版本，也不提供安装版自动更新；以后要使用应用内更新，仍需正式签名安装版。这是运行可信本地源码的方式，不经过安装包签名验证。

## 数据含义与刷新行为

| 显示项 | 本机 Codex 来源的含义 |
|---|---|
| 额度窗口 | 官方 `account/rateLimits/read` 返回的已用 / 剩余比例；各窗口独立显示，不相加 |
| 重置倒计时 | 按官方返回的重置时刻计算；归零不会自行恢复额度 |
| 剩余重置次数 | 仅在官方响应明确提供时显示，未知为「—」；工具不执行重置 |
| 独立额度 | 仅展示实际返回的独立额度记录，包括可识别的 Spark 记录；不凭模型名称编造窗口 |
| Token 统计 | 协议支持时读取 `account/usage/read` 的服务端统计，显示返回范围的累计及最新日桶；不把最新日桶冒充本机今日 |
| 成功读取时间 | 表示本次查询成功，不代表官方服务器的统计刚刚更新 |

Token 统计按当前官方 CLI 的协议能力读取，不支持时隐藏 Token 模块；可在设置的数据说明中了解统计范围。它不是扫描本机 Codex 会话日志得到的记录，也不承诺覆盖全部普通 ChatGPT 对话、所有设备历史或 API 账单。官方未提供、版本不支持或无法识别的字段保持未知；不能用额度百分比反推 Token 总数。

新安装点击连接并成功登录后自动开启读取；老用户保留已有方式。启用状态与间隔会保留，之后启动按设置继续查询。「暂停」仅停止刷新，保留登录和上次读数；自动配置模式下「退出此账号」会调用官方退出、停止刷新并清除该账号读数，仅影响此工具的独立登录。切换来源或连接方式会停止读取并清空当前读数；切回后需重新开启。刷新间隔可在桌面设置调整，也可立即查询。电脑睡眠、离线、CLI 缺失、登录过期或服务端延迟会影响读取；失败会显示原因并保留最近一次有效记录及其成功时间，不用失败尝试伪造新数据。检测到退出登录或账号变化时会清除旧账号读数，避免串账号。切换来源时明确标记当前来源，不把浏览器与 CLI 的数字拼成一份账号总量。

官方 App Server 接口目前具有实验性，版本变化可能影响兼容性。工具只使用固定的查询请求，解析不了的结构不会当作成功额度。详情见 [App Server 官方文档](https://learn.chatgpt.com/docs/app-server)。

## 浏览器同步作为备用来源

需要网页读取时，先在桌面选择「浏览器扩展」来源，再按以下步骤连接。两种来源由用户选择，不因一次 CLI 失败就自动切换到网页。

1. 在桌面点击「打开固定扩展文件夹」，Windows 通常为 `%APPDATA%\GPT Usage Orb Safe\Browser-Extension`，Mac 通常为 `~/Library/Application Support/GPT Usage Orb Safe/Browser-Extension`，以实际打开的位置为准。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启「开发者模式」，加载该目录。所选目录必须直接包含 `manifest.json`。此前加载 `Downloads` 中旧目录的用户需移除旧项并迁移一次；不要双击 `popup.html`。
3. 打开 <https://chatgpt.com/settings/usage?tab=overview>，只在官方网站完成登录。复制悬浮球当前配对码，从浏览器工具栏打开扩展，粘贴后点击「连接并开始读取」。配对码只允许本机数字同步，不是 GPT 登录码。

当前页面模式需保留用量页。备用的「后台定时刷新」可设 1–1440 分钟、默认 5，主动开启时申请 `https://chatgpt.com/*` 可选来源权限。每轮创建非活动临时用量标签页，读取后仅关闭本轮创建且未被用户接管的页面。浏览器授权覆盖整个来源，代码只在两个精确用量路径采集。点击「关闭并撤销授权」停止任务并撤销该权限。

**只有浏览器备用模式需要浏览器保持运行。** 配对及后台启用状态仅保留当前会话，桌面退出、浏览器重启或扩展重载后需重新配对；扩展重启后需重新开启定时任务。若从旧版切换到本机 Codex，建议先在扩展点击「关闭并撤销授权」，避免之前的扩展任务继续尝试打开页面。CLI 读取不需要浏览器扩展权限。

页面布局无法识别时，可在扩展手动填写页面明确显示的数字，未知项留空。填写的是**已用百分比**：剩余 80% 应填已用 20%。手动提交后暂停扩展自动读取，桌面标记为「人工记录」。页面读取时间不代表官方统计更新时间。

### 只维护浏览器扩展

```powershell
git pull --ff-only
if ($LASTEXITCODE -eq 0) { npm run extension:update }
```

此命令不需要 `npm ci`，只同步固定扩展目录，不启动桌面、不自动重载浏览器。随后在扩展管理页重新加载并确认 2.7.0，重新配对。它**不更新桌面，也不启用本机 Codex 来源**。2.1.1 等旧桌面不认识新版扩展清单，可能提示目录更新失败，但会保留现有文件；桌面升级后使用新版校验器。

## 玻璃效果与兼容性

设置中的「玻璃着色」从清透调至深色，只改变原生材质上的染色。面板在 Windows 上使用 DWM 材质，在 Mac 上使用原生 vibrancy；网页 CSS blur 不能跨窗口模糊桌面。本工具不会截图桌面来模拟效果，不需要屏幕录制或辅助功能权限。

圆球始终使用透明窗口与圆形区域，不再启用 Acrylic，也不再等待 GPU 检测结果。这样避免部分电脑上系统底材绘制出矩形底色；球面可透出后方应用颜色，边缘高光与内阴影用于呈现玻璃厚度，不宣称具有跨窗口模糊。详情面板在受支持的 Windows 11 上请求系统材质，在 Mac 上请求原生毛玻璃；实际效果受系统透明度设置、省电和驱动等条件影响。减少透明度或高对比度时使用清晰实色。

字体在 Apple 平台优先使用系统字体；Windows 内置 Inter（SIL Open Font License），配合等宽数字、适中的字重与紧凑字距。Apple SF Pro 未被打包，Windows 的原生鼠标提示使用系统提示字体。字体来源与许可证见 `assets/fonts/`。

## 日常使用和应用更新

悬浮球始终只显示剩余百分比，悬停或键盘聚焦后轻微放大，移开缩回；额度窗口、来源和倒计时在鼠标悬停提示中查看。长按本身不改变位置，拖动以主进程屏幕坐标判断；小于阈值的抖动不保存为新位置。拖动调整位置，点击展开 / 收起详情面板。Windows 托盘菜单和 `Ctrl + Alt + G` 可找回面板；Mac 左键点击菜单栏图标展开面板，右键打开菜单，也可用 `⌘ + ⌥ + G`。置顶、透明度、额度提醒和开机启动可在设置中调整，开机启动默认关闭。Mac 的开机启动还可能需要在「系统设置 → 通用 → 登录项」允许；未公证版本不保证系统接受，失败时按界面提示处理。

已配置发布源的 Windows 安装版默认在启动约 10 秒后检查更新，之后每 6 小时检查一次，也可手动检查或关闭自动检查。程序验证 Ed25519 发布签名，再下载并校验安装包版本、长度及哈希；准备好后由你点击「重启并更新」。普通退出不会自动安装待更新包，网络或校验失败不影响当前版本继续运行。

**Mac 首版支持检查更新与下载入口，暂不自动替换应用。** 应用验证对应芯片的签名更新描述后，点击「下载 Mac 新版」会在浏览器打开本仓库的 DMG 下载。下载完成后退出悬浮球，将新应用拖入「应用程序」并替换旧版；设置、组件缓存与独立登录保留。应用仅验证更新描述，**不会校验浏览器下载到磁盘的 DMG**；发布页附有 SHA-256 文件供另行核对。

应用更新包含桌面、Electron 运行时及备用浏览器扩展。自动配置所用官方组件按固定版本独立下载、校验并缓存；本机已有 CLI 不由应用更新。显示设置和位置保留；浏览器配对码不持久保存。固定目录中的扩展更新后需在浏览器手动重新加载；只使用本机 Codex 时无需加载扩展。

只有已配置仓库与公钥的安装版能检查正式更新。开发运行、旧免安装包、未配置发布源的安装包不具备该能力；不要向 `update-config.json` 填入账号令牌。源码提交、版本标签、草稿 Release 均不等于已发布正式更新。

Windows 安装更新前备份用户数据目录中的 `preferences.json` 到 `recovery`。**这是设置备份，不是完整程序快照或 NSIS 安装失败后的自动回滚。** 安装中断时用同版本或较新可信安装包修复；手动恢复设置前退出程序，再将选定备份复制为 `preferences.json`。

## 账号与安全边界

- 自动配置使用应用独立的 `CODEX_HOME`，官方组件仅使用系统凭据库管理登录与续期；悬浮球不读取或复制 `auth.json`、Cookie、密码、访问令牌，也不记录原始 RPC 或扫描会话日志。已有 CLI 模式沿用原存储配置，不承诺该模式必然使用系统凭据库。
- 登录是 **官方 Codex 的正常账号授权，不是仅限用量的 OAuth scope**。应用将自身操作限制为连接、取消、退出以及固定用量查询，不发起模型任务、聊天或额度重置；这不代表被盗凭据也只有查询权限。
- 浏览器备用扩展只把有限数字发往 `127.0.0.1:43861`，校验来源、会话配对码及字段。浏览器中的官方登录仍由浏览器保管。
- 更新和组件下载不携带账号凭据，不要求 GitHub 登录或 PAT。没有自建云用量同步或额外遥测。发布私钥不进入安装包，原更新签名信任链不变。

本工具不是 OpenAI 官方应用，不能防御已控制本机或官方组件的恶意软件。完整边界见 [SECURITY.md](SECURITY.md)。若曾使用 1.0.0 的登录功能，需单独通过旧版或官方账号会话管理撤销；2.x 不读取、复用或删除那份旧凭据。

## 卸载与验证范围

自动配置用户如需移除本机登录，先在设置点击「退出此账号」，确认成功后再卸载。已有 CLI 模式需自行使用官方 CLI 退出，浏览器账号在浏览器中管理。「暂停」、退出应用、删除应用目录或卸载都不等于退出账号。

卸载前关闭开机启动并退出悬浮球；不再使用浏览器模式时移除扩展，再在 Windows「已安装的应用」卸载，或将 Mac「应用程序」中的应用移到废纸篓。用户目录中的设置、组件缓存和备份默认保留，确认不再需要后可删除；删除目录不保证移除系统凭据库中的登录项。

自动测试覆盖固定组件校验、登录状态与取消、查询边界、字段校验、来源切换和更新流程。模拟协议与离屏界面不接触真实账号，不能替代干净 Windows / Mac 电脑上的首次安装、官方网页登录、真实额度读取及升级验收。实际验证范围以各版发布记录为准。

## 源码、打包与发布

代码仓库：<https://github.com/icjunge/gpt-orb-safe>。开发需要 Node.js 22.12+，执行 `npm ci`、`npm test`，再用 `npm start` 启动。Windows 环境执行 `npm run build:win` 生成 NSIS 安装包；Mac 环境执行 `npm run build:mac:arm64` 或 `npm run build:mac:x64` 生成对应 DMG；运行安装后的桌面不需要 Node.js 或 Python；一键连接也无需这些开发工具。仅高级模式手动通过 npm 安装 CLI 时需要 Node.js/npm。

```sh
python scripts/package_windows.py --source-only --extension-zip --output dist
```

维护者按 [RELEASE.md](RELEASE.md) 使用既有仓库、公钥、发布私钥与受保护签名流程。已完成初始化的仓库不要重新生成密钥。GitHub Actions 构建及草稿发布不代表正式 Release 已公开。
