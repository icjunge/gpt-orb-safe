This application downloads the unmodified official native CLI only after the
user requests connection. It is cached separately from the application. It is
not bundled in the GPT Orb installer and does not require Node.js, npm or Git.

Both macOS archives were downloaded and their compressed hashes matched the
official release metadata. Their single ustar members, expanded sizes, SHA256,
native CPU types and minimum OS load commands were independently inspected.

The application requires macOS 13 or later because of its Electron runtime.
macOS credentials use the official apple-native keyring backend, with no
plaintext fallback. Codex derives the keychain account name from the SHA256 of
canonical CODEX_HOME (cli| followed by the first 16 hex digits), under service
"Codex Auth". GPT Orb uses its own CODEX_HOME, not the user's normal CLI home.
